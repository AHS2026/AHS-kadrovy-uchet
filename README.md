# Кадровый учёт — служба персонала (БНТУ)

Десктопная программа кадрового учёта для АХС. Все данные хранятся в базе
SQLite в файле `кадровый_учёт.db`, который создаётся рядом с программой.
Интерфейс откроется в окне браузера, но данные живут в базе на вашем
компьютере — чистка браузера или другой компьютер им не повредят.

## Что внутри

- `кадровый_учёт.py` — сама программа (Python 3.8+, стандартная библиотека,
  устанавливать ничего не нужно);
- `ui/index.html` — интерфейс;
- `кадровый_учёт.db` — база данных, создаётся автоматически при первом запуске.

Возможности (полностью повторяют ваш HTML-пример):

- **Сотрудники** — карточка: ФИО, дата рождения, пол, должность, подразделение,
  табельный номер, код профессии, телефоны, адреса, паспорт (номер, дата,
  кем выдан, личный номер), рост и размеры (одежда/обувь/головной убор,
  рукавицы/перчатки), даты оформления/приёма/увольнения, примечания; печать
  карточки (А4); поиск по ФИО/должности/подразделению с поиском внутри подразделения.
- **Исходящие запросы** — Инфоцентр УВД, характеристика с прошлого места
  работы (до двух с разными организациями), УВД администрации, внутренняя
  проверка (подан → ожидание ответа → результат да/нет); маршруты согласования
  с историей, рег. номер ОДО, выгрузка в Word (.doc).
- **Входящие запросы (студенты АХС)** — требователь, ФИО и год рождения
  студента, места работы в АХС, маршрут согласования.
- **Шаблоны документов** — свои тексты с подстановками ({ФИО}, {ФИОВин},
  {ДатаРождения}, {Организация} и др.), шрифт/размер/поля/центрирование,
  общие данные исполнителя.
- **Резервная копия** — выгрузка/восстановление всей базы в файл .json.

## Запуск

Нужен установленный Python 3.8+ (https://www.python.org/downloads/, на Windows
при установке отметьте галочку «Add Python to PATH»).

Двойной клик по `кадровый_учёт.py` или в терминале из папки программы:

```
python кадровый_учёт.py
```

Программа откроет окно браузера с интерфейсом. Держите запущенное окно
открытым, пока работаете с программой. Для выхода — Ctrl+C в окне программы
(закладка «Резервная копия» → выгрузка .json — делайте регулярно).

Полезные ключи:

```
python кадровый_учёт.py --port 9000     # другой порт (по умолчанию 8417)
python кадровый_учёт.py --no-browser    # не открывать браузер автоматически
```

## Перенос на другой компьютер

Скопируйте папку целиком (или `кадровый_учёт.py`, `ui/index.html` и базу
`кадровый_учёт.db`) — на новом компьютере программа продолжит с теми же
данными. Данные также переносятся через резервную копию .json
(вкладка «Резервная копия» → «Восстановить из копии»).
